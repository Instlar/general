# ZIP-пакет рецептов, версия 1

В корне архива находится `recipes.json` в UTF-8 с объектом `{"version": 1, "recipes": [...]}`. Для каждой записи нужен собственный WebP 960 × 640, до 2 МБ. Путь задаётся относительно корня архива, например `images/apple-oat-cake.webp`. Пакет содержит до 100 новых рецептов. Предел общего размера 32 МБ до и после распаковки.

Для структуры карточки можно использовать запись из `content/recipes.json` как образец. В пакете уберите `sourceKey` и добавьте `image` с путём и `source` со сведениями о первоисточнике.

| Поле | Содержание |
| --- | --- |
| `id` | Уникальный постоянный идентификатор из строчных латинских букв, цифр и дефисов. |
| `title`, `description` | Название и индивидуальное краткое описание блюда для поиска и каталога. Для новых карточек ориентир — 120–160 символов. |
| `intro` | Отдельное введение из 2–3 полезных предложений. Если поля нет в старой карточке, генератор использует `description`. |
| `kind` | Ключ из `KINDS` в `tools/render.py`, например `cake`, `porridge`, `syrniki` или `sandwich`. |
| `tags` | Массив ключей из `TAGS` в `tools/render.py`. Ставьте метку, если она соответствует составу или исходной порции. |
| `tracks`, `difficulty` | `tracks` — массив **ровно из одного значения**: `["everyday"]` («Простые рецепты»: привычные продукты и понятная технология) либо `["special"]` («Необычные рецепты»: непривычные ингредиенты или сочетания). Два значения одновременно недопустимы. `difficulty` — отдельный признак `easy` или `some-technique`. |
| `servings`, `mealTypes` | Целое число порций и необязательный массив приёмов пищи. Допустимы `breakfast`, `lunch`, `dinner`. |
| `cookingMethod`, `temp`, `bake`, `cook` | Способы `oven` (по умолчанию), `hob`, `no-cook`, `microwave`, `mixed`. Для духовки укажите `temp` в °C и `bake` в виде `[мин, макс]`. Для плиты, СВЧ и смешанного нагрева используйте `cook`, если время нагрева известно отдельно. Если известно только общее время, укажите его через `prep` и поясните в `timeNote`. Для блюд без нагрева достаточно времени подготовки. При точном времени нагрева повторите число. |
| `prep`, `extra`, `mode` | Время подготовки и дополнительные минуты, если известны. `mode` — уточнение режима нагрева. Неизвестные значения оставьте пустыми (`null`). |
| `usesOven` | Необязательное логическое поле для `mixed`. Укажите `true`, если один из этапов требует духовку или её гриль. |
| `timeNote`, `pantryExtra` | Необязательное пояснение о времени и массив дополнительных продуктов для подбора, например масло для смазывания, если его количество в источнике не указано. |
| `pan`, `panSize` | Текст с исходной формой. Необязательный `panSize` для пересчёта одиночной формы: `{"kind":"round","diameter":23}` или `{"kind":"rectangle","width":20,"length":30}` в сантиметрах. |
| `ingredients` | Объекты ингредиентов. См. ниже. |
| `steps` | Массив инструкций. В каждом месте, где нужно показать количество ингредиента, укажите его идентификатор в двойных фигурных скобках. |
| `doneness`, `storage`, `allergens` | Признаки готовности, хранение и массив аллергенов. |
| `tips` | Необязательный массив советов. |
| `imageAlt`, `image` | Что видно на иллюстрации и относительный путь к её файлу. |
| `source` | Объект с `url`, `title`, `author`, `status`. Статус `source-checked` означает сверку по источнику, `baked-tested` — реальную выпечку. Можно добавить `adaptation`, `review`, `runet` и `densitySources`. |

Ингредиент выглядит, например, так:

```json
{"id":"flour","label":"Цельнозерновая пшеничная мука","product":"Цельнозерновая мука","amount":113,"unit":"g","density":0.478}
```

Единицы `g`, `ml`, `tsp`, `tbsp`, `each`, `pinch`, `bunch`, `handful`. Укажите `density` в граммах на миллилитр только для количества в граммах с обоснованным пересчётом. `product` — короткое название для подбора, совпадающее с уже используемым названием того же продукта. Для технологически разных продуктов, например обычной и самоподнимающейся муки, используйте разные названия. Указанные в источнике небольшие меры и штуки сохраняются. Можно указать `optional: true` и текстовый `note`.

Пример шага: `Отмерьте {{flour}} муки и просейте её в миску.` Генератор вставит в шаг то же количество, что и в список ингредиентов. Для каждого ингредиента нужна хотя бы одна ссылка в шагах. Температура, время и размеры формы остаются текстом. Если продукт используется разными порциями, заведите отдельные записи для этих порций.

Идентификатор, название и нормализованный адрес источника сверяются со всем каталогом. Дубли блокируют импорт целого пакета. Замену существующей карточки проводят как редактуру исходных данных и повторную сборку, сохраняя её идентификатор.
