Конфиденциальность

Какие данные использует сайт.

Для просмотра рецептов регистрация не нужна. Отметки ингредиентов сохраняются в браузере на вашем устройстве. Их можно удалить, очистив данные этого сайта в настройках браузера.

Для понимания посещаемости используется собственная система статистики. В браузере создается случайный анонимный идентификатор посетителя (localStorage), а на сервер отправляются адрес открытой страницы, время активности видимой вкладки и домен сайта, с которого совершен переход. Мы не сохраняем IP-адреса, имена, электронную почту или User-Agent в базе статистики. Данные нужны для подсчета посещений, популярных страниц и источников переходов.

Чтобы отключить счетчик на этом устройстве, откройте сайт один раз с параметром ?__analytics=off. Вернуть подсчет можно через ?__analytics=on. Очистка данных сайта в браузере также удаляет идентификатор. Поставщик хостинга может вести собственные технические журналы запросов.
