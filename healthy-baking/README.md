# Здоровая выпечка — статический сайт

Независимый сайт с рецептами, построенный без npm, Node-сервера и базы данных. **Не имеет технической связи с «Тугариным».**

## Готово

- Главная страница с поиском, фильтрами и избранным.
- 11 исходно сверенных рецептов с собственными индексируемыми HTML-страницами (`public/recipes/<slug>/index.html`).
- Динамические порции, граммы / стаканы / ложки, выбор стакана 200/250 мл.
- Количество ингредиентов указано **в каждом шаге**, где используется продукт.
- Печать рецептов, отметки готовых продуктов/шагов, источник рецептуры и пометки о том, что редакционная проверка приготовлением ещё не проведена.
- Локальные сгенерированные изображения в WebP. Эти изображения **иллюстративные, а не фотография приготовления по конкретному рецепту**.
- Разметка Schema.org Recipe, robots.txt, генерация canonical и sitemap при наличии собственного домена.

### Запуск локально

```bash
cd healthy-baking
python3 -m http.server 8000 --directory public
```

Открой `http://localhost:8000`. Рецептам нужны нормальные HTTP URL, поэтому не открывай файлы напрямую через `file://`.

### Деплой в Timeweb App Platform

1. Создай новое **Frontend** приложение в своём проекте «Сайты».
2. Репозиторий: `Instlar/general`, ветка `master`.
3. Фреймворк: **HTML/CSS/JS** (готовая статика, без Node-команды).
4. **Путь до директории проекта:** `healthy-baking/public`. Внутри уже находится `index.html`.
5. Сборка не требуется; ничего не указывай в полях команды сборки / npm.
6. Имя приложения: `Здоровая выпечка`; проект Timeweb: `Сайты`.
7. Создай приложение и проверь технический URL, который выдаст Timeweb с бесплатным HTTPS. **Никаких изменений в приложениях «Тугарина» делать не нужно.**
8. Когда появится собственный домен, подключи его к приложению и запусти `SITE_ORIGIN=https://твой-домен.ru python3 scripts/build.py`, а затем закоммить обновлённые `public/*.html`, `public/recipes/**`, `public/sitemap.xml` и `public/robots.txt`. Без указания `SITE_ORIGIN` canonical и sitemap намеренно не генерируются, чтобы не индексировать неправильный адрес.

Документация Timeweb: https://timeweb.cloud/docs/apps/deploying-frontend-apps/static-website

### Контент

Исходные рецепты: `data/recipes.json`. Генератор HTML: `scripts/build.py`.
После правки данных запусти:

```bash
python3 scripts/build.py
python3 -m unittest discover -s tests
```

Все изменения HTML сохраняются непосредственно в `public/`. Timeweb для HTML/CSS/JS **не запускает сборку**.

### Требования к следующим рецептам

- Никаких выдуманных пропорций и температур — нужен надёжный конкретный первоисточник и ссылка.
- Названия/описания/шаги должны быть собственными, без копирования чужих текстов.
- Точное количество для каждого употребления ингредиента; формат `{{flour}}` либо `{{juice:0.5}}` для половины количества.
- Если авторский рецепт изменён, это нужно ясно указать, а значимые изменения отдельно протестировать.
- Никаких придуманных оценок, комментариев, калорийности или заявлений, что редакция лично проверила рецепты.
- Изображения: собственные, оригинальные сгенерированные с пометкой, либо разрешённые с надлежащим указанием автора; не копировать фото первоисточников.

## ZIP-пакеты от Astra / Codex — будущий импорт

Новый формат описан в `data/BUNDLE_FORMAT.md`. Сейчас пакетирование служит техническим контрактом: **кнопка загрузки на сам сайт не реализована**, поскольку статическая витрина не имеет защищённой серверной записи. Для публикации ZIP одним нажатием позднее понадобится отдельный защищённый импортёр, который валидирует архив и сохраняет результат в GitHub, после чего Timeweb его развернёт. Нельзя делать публичный импорт или хранить GitHub-токен в JS браузера.

## Аналитика

Сайт готов к подключению созданного ранее самостоятельного счётчика с `data-site="baking"`. **Счётчик не включён**, поскольку сервис статистики пока не имеет публичного адреса. Его нельзя подменять игровым API или смешивать с базой «Тугарина».

После отдельного размещения аналитики вставь перед `</body>` в шаблон `scripts/build.py` (в `foot`) вызов:

```html
<script defer src="https://YOUR-STATS-DOMAIN/tracker.js" data-site="baking"></script>
```

Настрой точный HTTPS-домен выпечки среди разрешённых Origins аналитического сервиса. Без этого показатели посещений в собственной админке останутся пустыми.

## Частная жизнь

Избранное хранится в локальном браузере. На странице конфиденциальности описано, как будет работать статистика после её включения. При добавлении внешних рекламных/аналитических систем политику необходимо обновить.
