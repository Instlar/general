# Здоровая выпечка

Статический русскоязычный каталог. Готовый сайт находится в `public/`. HTML каждого рецепта содержит ингредиенты, шаги, признаки готовности, условия хранения и аллергены. JavaScript добавляет поиск, фильтры, подбор по продуктам, отметки, пересчёт мер, порций и форм.

«Из обычных продуктов» и «Выпечка с особым составом» — отдельные разделы с общими карточками. У рецепта сохраняется один адрес, даже если он входит в оба раздела и в дополнительные подборки.

## Настройки Timeweb Cloud

1. Создайте приложение **Frontend** и выберите **HTML/CSS/JS**.
2. Подключите `Instlar/general` и выберите ветку `healthy-baking-v1`.
3. В поле «Путь до директории проекта» введите `healthy-baking/public`.
4. Запустите публикацию. В этой папке уже есть `index.html`, изображения и все остальные файлы сайта.

## Обновление сайта на компьютере

Запускайте команды из каталога `healthy-baking`. Для генерации и импорта достаточно Python 3.10 или новее.

```sh
python tools/site.py build
python -m http.server 8097 --bind 127.0.0.1 --directory public
```

Просмотр доступен на локальном адресе `http://127.0.0.1:8097/`.

Когда у сайта появится постоянный публичный адрес, передайте его параметром `--site-url` в команде `python tools/site.py build`. Нужен HTTPS-адрес без пути или параметров. Генератор сохранит его в `content/site.json`, добавит canonical и абсолютные адреса Open Graph и Schema.org, создаст `sitemap.xml` и укажет его в `robots.txt`. Затем закоммитьте `content/site.json` и `public/`. Дальнейшие сборки и импорты используют сохранённый адрес. Без него сайт работает с относительными адресами внутри сайта, а canonical и sitemap откладываются до получения адреса.

## Новый рецепт из ZIP

```sh
python tools/site.py import path/to/recipes.zip
```

Команда проверяет пакет и дубли по идентификатору, названию и источнику, добавляет новые записи и пересобирает готовые страницы. После проверки результата закоммитьте `content/` и `public/`. Схема пакета описана в [формате импорта](tools/BUNDLE_FORMAT.md).

Полные сведения об источниках новых рецептов сохраняются в локальном файле `editorial-sources.local.json`, исключённом из Git. В `content/recipes.json` хранится только отпечаток URL для обнаружения дублей. В публичный HTML сведения об источниках не попадают.

## Проверка

```sh
python tests/test_site.py
```

Браузерный тест `node tests/browser.cjs` использует Playwright в локальном окружении и запущенный статический сервер. По умолчанию адрес `http://127.0.0.1:8097/`. Его можно изменить переменной `SITE_TEST_URL`, а установленный Chrome выбрать через `CHROME_PATH`.
