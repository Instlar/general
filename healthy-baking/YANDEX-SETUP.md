# Настройка Яндекс Метрики и Вебмастера

Настройки публичных идентификаторов находятся в `content/site.json`:

```json
{
  "siteUrl": "https://pekizdorovo.ru",
  "yandex": {
    "metrikaCounterId": null,
    "webmasterVerification": null
  }
}
```

## Метрика

Создайте **отдельный** счётчик в https://metrika.yandex.ru/ для `https://pekizdorovo.ru`. Публичный номер впишите в `metrikaCounterId` (целое число). После сборки на всех страницах будет подключён локальный `/yandex-metrika.js`, который загрузит официальный `https://mc.yandex.ru/metrika/tag.js`. Пока указан `null`, внешний код не загружается.

Не включайте Webvisor автоматически и не записывайте в события списки продуктов пользователя или персональную информацию. Собственная статистика проекта продолжит работать независимо.

## Вебмастер

Добавьте `https://pekizdorovo.ru` в https://webmaster.yandex.ru/. Выберите проверку через метатег и впишите полученное **публичное** значение токена в `webmasterVerification`, затем дождитесь сборки и нажмите «Подтвердить» в Вебмастере. Метатег будет присутствовать только на главной странице. При необходимости вместо метатега можно использовать персональный HTML-файл, который выдаст сам Яндекс; не придумывайте его имя или содержимое.

`/robots.txt` и `/sitemap.xml` уже создаются генератором.

## Рекламная сеть Яндекса

Добавьте **отдельную площадку** в личном кабинете РСЯ, подтвердите домен через Вебмастер или выданный Яндексом `ads.txt`. `ads.txt` нельзя генерировать с вымышленным ID партнёра. Рекламные блоки не размещать до получения ID сайта/блока, проверки модерации и согласования мест в дизайне.

## Отключение аналитики для тестов

Переход с `?__analytics=off` отключает собственный счетчик и Метрику для этого браузера; `?__analytics=on` возвращает сбор. Статистика может не совпадать с Метрикой из-за фильтрации, блокировщиков и правил учета.
