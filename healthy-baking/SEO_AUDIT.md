# SEO-аудит сайта «Здоровая выпечка» — 6 ноября 2026

## Проверено в GitHub

- 38 статических HTML-страниц, из них 23 самостоятельные страницы рецептов. Страницы читаемы без JavaScript.
- Для всех страниц предусмотрены `title`, `description`, H1, canonical и Open Graph.
- Для рецептов используется `Recipe`, для подборок `ItemList`, для внутренних страниц `BreadcrumbList`.
- Присутствуют XML-карта сайта на `https://pekizdorovo.ru/` и `robots.txt` со ссылкой на неё.
- Изображения в WebP, HTML содержит alt, фиксированные размеры, отложенную загрузку вне первого экрана.
- Ингредиенты и шаги доступны в статическом HTML, интерактивный пересчёт не является условием просмотра.
- Простые и необычные рецепты представлены двумя отдельными разделами без дублирования рецептов по порциям.

7. Расширены проверки генератора на SEO-описания, метатеги и структурированные данные.

## Ограничения и дальнейшие действия

- Анализ выполнен по исходникам в GitHub; работающий публичный домен, DNS, заголовки ответа сервера, Core Web Vitals и индексируемость Google/Яндекса отдельно не подтверждены.
- Не проводилась оценка частотности Wordstat, позиций и конкуренции по конкретным запросам — прогнозировать органический трафик пока нельзя.
- Фотографии еды являются иллюстрациями; их соответствие требованиям расширенных результатов Google лучше отдельно проверить. Не выдавать иллюстрации ИИ за фотографии реально приготовленных блюд.
- Тексты и пропорции рецептов требуют редакционного контроля. Поисковое описание не делает рецептуру экспериментально проверенной.
- После настройки DNS основного домена проверьте `/robots.txt`, `/sitemap.xml`, несколько URL рецептов, canonical, статус HTTP 200 и инструмент Google Rich Results Test, затем добавьте карту сайта в оба кабинета вебмастера.
- Дальнейшее наполнение планировать по поисковым данным, а не по механическому повторению ключевых слов.
